# Разведочный анализ данных (EDA)

Дата: 2026-09-16. Инструменты: duckdb + pandas поверх `dataset/*.parquet`.
Все числа ниже посчитаны на полных данных, если не указано «выборка».

## 1. Файлы и столбцы

| Файл | Строк | Что это |
|---|---|---|
| `train.parquet` | 497 673 | пары «запрос → выбранное объявление», все `search_*` + все `item_*` (включая `item_id`) |
| `benchmark_queries.parquet` | 2 452 | `query_id` + `search_*`, без разметки |

Пропуски: текстовые поля не NULL, «пусто» = пустая строка. NULL только в рейтинге
(train 5.7 %, корпус 9.3 %) и числе отзывов (3.9 % / 6.1 %). Описание пустое у 0.02 % корпуса.

## 2. Запросы

- Трейн: 74 529 уникальных текстов, в среднем 2.3 слова. Голова: «маникюр» 6 540, «массаж» 5 702,
  «наращивание ресниц» 5 395, «установка кондиционеров» 4 573, «педикюр», «сантехник», «вывоз мусора»…
- Бенчмарк: **каждый текст уникален** (2 452 запроса = 2 452 текста), 3.2 слова, 23 символа — длиннее, «хвостовее».
- **Только 37 % текстов бенчмарка встречаются в трейне**; медианная частота в трейне = 0, p75 = 2, p90 = 7.
- Особенности текста: всё в нижнем регистре; латиница 4.9 % (трейн 2.9 %), цифры 3.8 %, пунктуация 1.3 %.
  Встречаются топонимы в тексте («грузоперевозки красногорск», «вывоз мусора, тогучинский район»),
  опечатки/склейки («унитазетранению»), «master на час», бренды («huawei», «sea pro»),
  не-сервисные интенты («куплю холодильник», «сдать сломанный жк телевизор» — скупка).

## 3. Категории

- `search_category`: трейн — 114 у 99.99 %; **бенчмарк — 222 запроса (9 %) с категорией 0** (поиск без категории),
  в трейне таких всего 34 строки → сдвиг распределения.
- `item_category_id`: в трейне 114 у 99.99 %; в корпусе 114 у 99 % (187 336), остальные 1 876 объявлений — 46 «чужих»
  категорий (товары, недвижимость, вакансии: срубы, запчасти, квартиры). Скорее всего дистракторы.
- `item_microcat_id`: корпус — 752 значения (178 с ≥100 объявлений, 524 с <10); трейн — 252.
  - 99.1 % объявлений корпуса попадают в микрокатегории, встречавшиеся в трейне; 546 микрокатегорий корпуса
    (1 758 объявлений) в трейне не встречались — это почти всё хвост и нерелевантные категории.
  - Микрокатегория ≈ пара («Вид услуги», «Тип услуги»): чистота в среднем 96 %, медиана 100 %.
- **Запрос почти однозначно определяет микрокатегорию:** по запросам трейна с ≥5 выборами доля топ-1 микрокатегории 82 %,
  топ-3 — 98 %; взвешенно по строкам топ-1 = 86 %.
- Сдвиг состава: в корпусе больше репетиторов (86456: 3.4 % против 0.7 % в трейне), в трейне больше автосервиса
  (1289835: 5.8 % против 2.0 %). Корпус собран не как «выбранные объявления», а шире.

## 5. Фильтры поиска (`search_infm_params_text`)

- Непустые: трейн 67 %, **бенчмарк только 37 %** (1 546 пустых) → сдвиг.
- Формат тот же «ключ значение». Ключи: `Вид услуги`, `Тип услуги`, `Тип услуги автосервиса`, `Предмет или специальность`,
  `Кто оказывает услуги`, `Онлайн-запись`. 60 запросов бенчмарка с «Вид услуги» без значения.
- **Фильтр «Вид услуги X» совпадает с «Вид услуги» выбранного объявления в 98.4 % случаев** → почти жёсткий фильтр.
- «Тип услуги» совпадает в 95.4 % (точным парсером, см. раздел 13; грубая регулярка давала ~86 %).
- Все значения «Вид услуги» из фильтров бенчмарка присутствуют в корпусе.

## 6. География

- Ключевая находка: **`search_location_id` бывает двух уровней.**
  - «Город» — id встречается среди `item_location_id`. Трейн 89 % строк, бенчмарк 82.7 %.
    **Выбранное объявление в той же локации в 93.2 %.** Медиана расстояния до центра локации 2.6 км, p99 20 км.
  - «Регион/страна» — id никогда не бывает у объявлений (107620, 621540, 107621, 637680, …). Трейн 10.8 %,
    **бенчмарк 17.3 %** → сдвиг. Совпадение локации там 0 по определению; 107620 → 233 разных города в трейне,
    621540 (вероятно, вся Россия) → 590.
- Для всех региональных id бенчмарка в трейне есть наблюдённое отображение «регион → города».
- Когда выбранное объявление не в городе поиска (городской уровень): медиана 34 км, 46 % в пределах 30 км, 75 % — 100 км.
  Это соседние населённые пункты / область.
- Координаты поиска не даны → центр локации можно восстановить как медиану координат объявлений этой локации.
- Самые частые локации: 637640 (скорее всего Москва: 36 тыс. строк трейна, 329 запросов бенчмарка, 19.5 тыс. объявлений),
  653240 (скорее всего Санкт-Петербург).
- 79 % корпуса лежит в городах, где есть запросы бенчмарка; 99.4 % — в городах из трейна.

## 7. Сколько «правильных» ответов на запрос

По трейну (сессия = текст + локация + фильтры + категория): 1 выбор — 85 %, 2 — 9.5 %, 3 — 2.6 %, хвост до сотен.
Среднее 1.32; средняя величина 1/|релевантные| = 0.91. Для бенчмарка ожидаем в основном 1–2 релевантных.
Полных дублей строк в трейне ~31 тыс. (одна пара выбрана несколько раз).

## 8. Объявления: пересечения, популярность, дубли

- **Только 5.3 % объявлений трейна есть в корпусе**, 9.6 % корпуса встречались в трейне → запоминать `item_id` почти бесполезно.
- Популярность в трейне плоская: медиана 1 выбор на объявление, p99 = 6, максимум 188.
- Дубли в корпусе: 189 тыс. объявлений, но 120 тыс. уникальных заголовков; 6 403 группы одинаковых описаний
  (27 тыс. объявлений, до 80 копий), обычно в разных городах (медиана 3). Шаблонные заголовки: «Наращивание ресниц» ×869,
  «Репетитор по английскому языку» ×574, «Маникюр» ×504. Внутри одной локации одинаковые тексты не различимы
  по тексту → там решают гео и поведенческие признаки.
- Цена: медиана 1 000; 7.6–8.8 % ≤ 0 (−1 = «договорная»), есть мусор до 10¹². Как признак почти бесполезна.
- Отзывы у выбранных выше, чем в корпусе (медиана 25 против 18; без отзывов 5.8 % против 8.8 %). Рейтинг <4.5: 6.2 % против 7.4 %.
  Телефон скрыт: 12.1 % против 15.6 %; сообщения запрещены: 2.1 % против 2.7 %. Слабые, но стабильные сигналы.

## 11. Сдвиги трейн → бенчмарк (учитывать в валидации)

1. Запросы бенчмарка уникальны и длиннее; 63 % не встречались в трейне.
2. Фильтров меньше: 37 % против 67 %.
3. Региональных поисков больше: 17 % против 11 %.
4. Категория 0: 9 % против ~0 %.
5. Состав корпуса ≠ состав выборов трейна (больше обучения, меньше автосервиса).
→ Валидационную выборку из трейна нужно перевзвесить под эти доли.

## 12. Кандидаты в гипотезы (от дешёвых к дорогим)

1. Гео-фильтр: город поиска; регион → города по отображению из трейна; расширение на соседей по расстоянию.
2. Жёсткий фильтр по «Вид услуги» (и мягкий по «Тип услуги»), если задан.
3. Если пул ≤ 50 — отдать весь пул; иначе ранжировать внутри пула.
4. «Запрос → микрокатегория»: словарь по трейну для известных запросов, классификатор для новых; фильтр или буст.
5. BM25 по заголовку + полезным ключам параметров + описанию с лемматизацией/стеммингом, внутри гео-пула.
6. Поведенческий буст: число отзывов, рейтинг, телефон/сообщения — для добивки до 50 одинаковых по тексту объявлений.
7. Топонимы в тексте запроса → уточнение локации.
8. Расширение запроса похожими запросами трейна (их выбранные заголовки и микрокатегории).
9. Эмбеддинги (e5 / rubert) для 2.5 % запросов без общих слов и новых формулировок.
10. Объединение источников и обученный отбор 50.

### 13.5 Итог: какие дополнительные признаки можно извлечь

- **Из параметров объявления:** Вид услуги, Тип услуги, Тип услуги автосервиса, Предмет/Специальность, прайс-лист
  (названия услуг — отдельное текстовое поле), марка/модель/производители, режим работы, зона выезда, онлайн-запись,
  опыт работы, договор/гарантия, адрес (город/район/улица), число позиций прайса.
- **Из запроса:** топоним, намерение, модификаторы, бренд/латиница, числа; стоп-слова.
- **Парные признаки:** совпадение значений фильтров; BM25 по полям отдельно; совпадение топонима запроса с адресом;
  тот же город / расстояние / вероятность «регион → город»; вероятность «запрос → подкатегория»; онлайн-запись при таком фильтре.
